# Display panel direction

The primary task is understanding the current display arrangement and keeping the wireless screen connected. Preserve connect, disconnect, quit, layout access, keyboard navigation, and connection diagnostics.

Replace the separate error window and command menu with one native menu-bar popover. Start with the real display count and a scaled map of CoreGraphics display bounds; identify the wireless output with one system accent color. List actual display names and dimensions below the map. Keep connection state and one primary action together. Use native typography, semantic colors, and material rather than gradients, decorative metrics, or promotional cards.

The map is read-only. Display Settings remains the place to rearrange screens. Reopening the application opens the same panel. Retry, offline, connected, and intentionally disconnected states share one layout. A closed panel does not stop streaming.
